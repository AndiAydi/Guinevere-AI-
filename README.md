# Guinevere AI
An **AI companion** with four switchable modes: Companion, Roleplay, Deep Reasoning, and Deep Research.

This project is still in early development. Structure, stack, and features may change at any time.

Features:

## 1. AI Companion
Mode for daily conversation. Keeps company, listens, and gives warm responses without being over the top.

## 2. Roleplay
Mode for roleplaying and storytelling. Maintains character consistency across long conversations.

## 3. Deep Reasoning
Mode for helping with coding, debugging, and technical problem-solving. Focuses on solutions, not small talk.

## 4. Deep Research
Mode for topic analysis and research. Organizes information in a structured way and separates facts from opinions.
